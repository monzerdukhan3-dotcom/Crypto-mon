# روتين المدير

كل بند يشير للرحلة التي ينفذها في [`journeys.md`](journeys.md).

## يومياً

### صباحاً (~30 دقيقة)
- [ ] **طلبات الانضمام**: اقبل أو ضع في الانتظار — م-1
- [ ] **المحادثات الخاصة**: رد على كل رسالة، واستقبل إثباتات الدفع — ر-7 / م-11
- [ ] **الدفعات**: افتح الحساب البنكي/المحفظة، طابق كل مبلغ وصل بإثباته، سجّل وفعّل — م-3
- [ ] **المشتركون**: فرز حسب نهاية التجربة/الاشتراك — أرسل تذكيرات الـ3 أيام، أنهِ من انتهت فترته — م-10

### جلسة التحليل (~60 دقيقة)
- [ ] مراجعة أسعار العملات العشرين النشطة والأخبار المؤثرة — م-4
- [ ] صياغة توصية إن وُجدت فرصة (لا توصية أفضل من توصية ضعيفة)
- [ ] قبل النشر: إعادة فحص السعر لحظياً، ثم النشر والأرشفة فوراً — م-5

### مساءً (~20 دقيقة)
- [ ] **النتائج**: كل توصية حان موعد تقييمها ← سجّل الحكم وانشر النتيجة — م-8
- [ ] **الأرشفة**: كل توصية في القناة اليوم لها صف في `التوصيات` — م-7
- [ ] **المحادثات الخاصة**: لا رسالة بلا رد — م-11

## أسبوعياً (أو حسب `{دورية_الملخص}`)
- [ ] انشر ملخص الأداء وثبّته، مهما كانت النتائج — م-9
- [ ] طابق عدد أعضاء القناة مع (`مجاني` + `مدفوع`) في الجدول — م-10
- [ ] راجع `العملات المراقبة`: هل تبقى القائمة كما هي؟ (تعطيل عملة = `نشطة` = لا، لا تحذف الصف)

## شهرياً
- [ ] راجع مجموع الدفعات المؤكدة في `الدفعات` مقابل كشف الحساب
- [ ] راجع قائمة الانتظار: هل الحد المجاني ما زال مناسباً؟
- [ ] نسخة احتياطية من ملف الجداول (تصدير)

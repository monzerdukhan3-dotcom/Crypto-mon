# قوالب الجداول

استورد كل ملف كتبويب منفصل في ملف Google Sheets واحد (ملف ← استيراد ← إدراج أوراق جديدة).
الملفات بترميز UTF-8 مع BOM حتى تظهر العربية صحيحة في Excel أيضاً.

| الملف | التبويب | كيان المواصفات |
|---|---|---|
| `subscribers.csv` | المشتركون | المشترك |
| `payments.csv` | الدفعات | الدفعة (كل دفعة تخص مشتركاً واحداً عبر `معرّف المشترك`) |
| `recommendations.csv` | التوصيات | التوصية (كل توصية تخص عملة واحدة من `العملات المراقبة`) |
| `results.csv` | النتائج | نتيجة التوصية (صف واحد لكل توصية عبر `رقم التوصية`) |
| `watchlist.csv` | العملات المراقبة | العملة المراقَبة — 20 صفاً فارغاً، املأ أسماء العملات |

## القيم المسموحة

| العمود | القيم |
|---|---|
| المشتركون ← الحالة | `انتظار` · `مجاني` · `مدفوع` · `منتهي` |
| الدفعات ← مؤكدة الوصول / مكتملة | `نعم` · `لا` |
| التوصيات ← النوع | `شراء` · `بيع` |
| التوصيات ← الحالة | `منشورة` · `أُلغيت قبل النشر` |
| التوصيات ← عُدّلت / أُلغيت | `نعم` · `لا` |
| النتائج ← الحكم | `ربح` · `خسارة` · `غير محسوم` · `ملغاة` |
| العملات المراقبة ← نشطة | `نعم` · `لا` |

نصيحة: في Google Sheets حوّل هذه الأعمدة إلى قوائم منسدلة (بيانات ← التحقق من صحة البيانات) لتجنب الأخطاء الإملائية.

## المعرّفات

- المشترك `S-0001`، الدفعة `P-0001`، التوصية `R-0001`، العملة `C-01` — أرقام متسلسلة لا يُعاد استخدامها.
- `S-xxxx` هو نفسه **رمز المرجع** الذي يكتبه المشترك في ملاحظة التحويل.
- `R-xxxx` يظهر في منشور التوصية نفسه، فيربط القناة بالأرشيف وبالنتيجة وبالتصحيحات.
- الصفوف لا تُحذف أبداً: المشترك المغادر يصبح `منتهي`، والعملة المستبعدة تصبح `نشطة = لا`.

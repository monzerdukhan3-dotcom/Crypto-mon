# نصوص الرسائل الجاهزة

استبدل كل `{…}` قبل الإرسال. الرسائل `ن-01` إلى `ن-09` تُرسل في **محادثة خاصة**، والرسائل `ن-10` إلى `ن-14`
تُنشر في **القناة**.

---

## رسائل المشتركين (محادثة خاصة)

### ن-01 · الترحيب بعد القبول
```
أهلاً {الاسم} 👋 تم قبولك في القناة.

• الفترة التجريبية المجانية: من {تاريخ_الانضمام} إلى {نهاية_التجربة}.
• ستصلك كل توصية في القناة مع السبب والسعر وقت النشر، ثم نتيجتها (ربح / خسارة / غير محسوم).
• كل أسبوع ننشر ملخصاً بكل التوصيات — الرابحة والخاسرة — بدون استثناء.
• التنفيذ عليك وعلى منصتك؛ لا نتداول نيابة عن أحد ولا نطلب بيانات حسابك.

⚠️ التوصيات اجتهاد وتحليل وليست ضماناً للربح. لا تستثمر مالاً لا تتحمل خسارته.

لأي استفسار: راسلني هنا مباشرة.
رقمك عندنا: {معرّف_المشترك}
```

### ن-02 · قائمة الانتظار
```
أهلاً {الاسم}، شكراً لاهتمامك.
الأماكن المجانية مكتملة حالياً، وأضفناك لقائمة الانتظار (ترتيبك: {الترتيب}).
سنراسلك هنا فور توفر مكان.
```

### ن-03 · تذكير نهاية التجربة
```
أهلاً {الاسم}، فترتك التجريبية تنتهي يوم {نهاية_التجربة}.

خلال فترتك نُشرت {العدد} توصية:
✅ ربح: {عدد_الربح}   ❌ خسارة: {عدد_الخسارة}   ➖ غير محسوم: {عدد_غير_محسوم}   ⏳ لم يحن تقييمها: {عدد_معلق}
(التفاصيل في الملخصات المثبتة بالقناة)

للاستمرار بعد التجربة: الاشتراك الشهري {المبلغ}. رد بـ"اشتراك" وأرسل لك خطوات الدفع.
```

### ن-04 · تفاصيل الدفع
```
تفاصيل الاشتراك الشهري:

💰 المبلغ: {المبلغ} (كاملاً — لا يُفعّل الاشتراك بمبلغ ناقص)
🏦 الوسيلة: {وسيلة_الدفع}
📄 بيانات الحساب: {بيانات_الحساب}
🔖 رمز المرجع: {معرّف_المشترك} — اكتبه في ملاحظة التحويل إن أمكن

بعد التحويل أرسل هنا صورة الإيصال أو رقم العملية.
التفعيل يتم بعد تأكدنا من وصول المبلغ فعلياً، وسنبلغك فوراً.
```

### ن-05 · تأكيد التفعيل
```
✅ تم استلام {المبلغ} وتفعيل اشتراكك.
الفترة: من {بداية_الاشتراك} إلى {نهاية_الاشتراك}.
سنذكّرك قبل انتهائها بـ3 أيام. شكراً لثقتك.
```

### ن-06 · تذكير التجديد
```
أهلاً {الاسم}، اشتراكك ينتهي يوم {نهاية_الاشتراك}.

أداء هذا الشهر: {العدد} توصية — ✅ {عدد_الربح}  ❌ {عدد_الخسارة}  ➖ {عدد_غير_محسوم}

للتجديد: {المبلغ} عبر {وسيلة_الدفع} — {بيانات_الحساب}، رمز المرجع {معرّف_المشترك}.
الفترة الجديدة تبدأ من {نهاية_الاشتراك} مهما كان يوم الدفع.
إن لم يصل التجديد، تنتهي عضويتك في القناة يوم {نهاية_الاشتراك}.
```

### ن-07 · استلام استفسار (رد مؤقت)
```
وصلتني رسالتك، سأرد عليك خلال {المدة}.
```

### ن-07ب · رد على شكوى من الخسائر (حتى تُحسم سياسة الاسترداد)
```
أتفهم انزعاجك من الخسارة. كل التوصيات ونتائجها منشورة كما هي في القناة، بما فيها الخسائر،
والتوصيات اجتهاد تحليلي وليست ضماناً للربح كما ذكرنا عند الانضمام.
التنفيذ وحجم الصفقة قرارك، وننصح دائماً بعدم المخاطرة بأكثر مما تتحمل خسارته.
إن كان لديك ملاحظة على توصية بعينها، أرسل رقمها وسأراجعها معك.
```

### ن-08أ · إثبات غير واضح / المبلغ لم يظهر
```
شكراً، لكن لم يظهر المبلغ في حسابنا حتى الآن.
أرسل من فضلك {رقم العملية / صورة أوضح للإيصال / اسم المحوّل}.
لن يُفعّل الاشتراك قبل التأكد من وصول المبلغ فعلياً.
```

### ن-08ب · مبلغ ناقص
```
وصلنا {المبلغ_المستلم}، والمطلوب {المبلغ}.
المتبقي: {الفرق} — يُرسل على نفس الحساب مع رمز المرجع {معرّف_المشترك}.
يُفعّل الاشتراك فور اكتمال المبلغ.
```

### ن-08ج · دفعة غير معروفة المصدر
```
وصلتنا دفعة بتاريخ {التاريخ} ولم نستطع ربطها بصاحبها.
إن كنت حوّلت في هذه الفترة، أرسل لي: المبلغ بالضبط، وقت التحويل، واسم المحوّل كما يظهر في البنك.
```

### ن-09 · انتهاء العضوية
```
أهلاً {الاسم}، انتهت {فترتك التجريبية / فترة اشتراكك} اليوم ولم يصل تجديد، فتمت إزالتك من القناة.
إن أردت العودة في أي وقت، راسلني هنا وأرسل لك خطوات الدفع.
شكراً لوجودك معنا.
```

## منشورات القناة

### ن-10 · توصية
```
📌 توصية {رقم_التوصية}

العملة: {العملة}/USDT
النوع: {🟢 شراء | 🔴 بيع}
السعر وقت النشر: {السعر}
السبب: {سطران أو ثلاثة: التحليل الفني + الخبر المؤثر إن وجد}
موعد تقييم النتيجة: {تاريخ_ووقت_التقييم}

⚠️ اجتهاد تحليلي وليس ضماناً للربح. التنفيذ على مسؤوليتك.
```

### ن-11 · تصحيح (Reply على التوصية الأصلية)
```
✏️ تصحيح على {رقم_التوصية}

الخطأ: {ما كُتب}
الصحيح: {القيمة الصحيحة}

باقي تفاصيل التوصية كما هي.
```

### ن-12 · إلغاء بعد النشر (Reply على التوصية الأصلية)
```
⛔ إلغاء {رقم_التوصية}

السبب: {مثال: السعر تحرك إلى {السعر_الحالي} وألغى سبب الدخول}
هذه التوصية ستظهر في الملخص القادم كـ"ملغاة".
```

### ن-13 · نتيجة توصية (Reply على التوصية الأصلية)
```
📊 نتيجة {رقم_التوصية} — {العملة} {شراء|بيع}

سعر النشر: {سعر_النشر}
سعر التقييم ({تاريخ_التقييم}): {سعر_التقييم}
التغير: {النسبة}%

الحكم: {✅ ربح | ❌ خسارة | ➖ غير محسوم}
```

### ن-14 · ملخص الأداء الدوري (يُثبَّت)
```
📈 ملخص الأداء: {من_تاريخ} → {إلى_تاريخ}

إجمالي التوصيات: {العدد}
✅ ربح: {عدد_الربح}
❌ خسارة: {عدد_الخسارة}
➖ غير محسوم: {عدد_غير_محسوم}
⛔ ملغاة: {عدد_الملغاة}
⏳ لم يحن تقييمها: {عدد_معلق}

التفاصيل (كل التوصيات بلا استثناء):
{رقم} · {العملة} · {شراء/بيع} · {الحكم} · {النسبة}%
{رقم} · {العملة} · {شراء/بيع} · {الحكم} · {النسبة}%
…

السجل الكامل لكل التوصيات السابقة في الملخصات المثبتة.
```

# قناة التوصيات — تشغيل الـMVP

هذا المجلد يحوّل مواصفات الـMVP إلى رحلات تشغيل يدوية جاهزة للتنفيذ. لا يوجد هنا كود: الـMVP يُدار بالكامل عبر
قناة تيليغرام + محادثات خاصة مع المدير + جداول بيانات (Google Sheets أو Excel).

| الملف | المحتوى |
|---|---|
| [`journeys.md`](journeys.md) | كل الرحلات خطوة بخطوة: رحلات المشترك، رحلات المدير، الحالات الاستثنائية، معيار "منتهية" لكل رحلة |
| [`messages.md`](messages.md) | نصوص الرسائل الجاهزة التي يرسلها المدير في كل خطوة (نسخ ولصق) |
| [`routine.md`](routine.md) | روتين المدير اليومي والأسبوعي والشهري |
| [`templates/`](templates/) | قوالب الجداول (CSV) — تُستورد في Google Sheets كتبويبات منفصلة |

## الأدوات المطلوبة لبدء التشغيل

1. **قناة تيليغرام خاصة** (Private Channel) — المدير وحده ينشر فيها. الانضمام عبر رابط دعوة بخيار
   "طلب الانضمام" (Request to Join) حتى يوافق المدير على كل طلب يدوياً.
2. **حساب تيليغرام للمدير** للمحادثات الخاصة (الاستفسارات، طلبات الترقية، إثباتات الدفع).
3. **ملف جداول واحد** فيه خمسة تبويبات منسوخة من `templates/`:
   `المشتركون`، `الدفعات`، `التوصيات`، `النتائج`، `العملات المراقبة`.
4. **مصدر أسعار** (TradingView / Binance / CoinGecko) و**مصدر أخبار** (CoinDesk / CoinTelegraph / X) للاستخدام اليدوي.
5. **وسيلة دفع محلية** واحدة على الأقل (تحويل بنكي / محفظة محلية / USDT).

## قرارات مطلوبة قبل الإطلاق

هذه القيم مذكورة في الرحلات كـ`{متغيرات}` لأن المواصفات لم تحددها:

| المتغير | الوصف | القيمة |
|---|---|---|
| `{مدة_التجربة}` | مدة الفترة التجريبية (بين أسبوعين وأربعة) | ☐ لم يُحدد |
| `{الحد_الأقصى_المجاني}` | الحد الأقصى للأعضاء المجانيين قبل قائمة الانتظار | ☐ لم يُحدد |
| `{المبلغ}` | مبلغ الاشتراك الشهري | ☐ لم يُحدد |
| `{وسيلة_الدفع}` | وسيلة/وسائل الدفع وتفاصيل الحساب | ☐ لم يُحدد |
| `{مدة_التقييم}` | المدة الافتراضية بين نشر التوصية وموعد تقييمها | ☐ لم يُحدد |
| `{عتبة_التعادل}` | نسبة الحركة التي تُعتبر تحتها التوصية "غير محسومة" | ☐ لم يُحدد |
| `{دورية_الملخص}` | أسبوعي أم كل أسبوعين | ☐ لم يُحدد |

والإضافات المقترحة في المواصفات (سياسة الاسترداد، إخلاء المسؤولية، فترة السماح بعد الانتهاء) تحتاج قرارك؛ الرحلات
تشير إليها كـ**قرار مفتوح** في مكانها بدل افتراض إجابة.
